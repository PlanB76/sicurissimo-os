# STRUMENTI81+ SPEC

## MODULI STRUMENTI IN DASHBOARD

### Calcolatrice Rischio
Calcola il livello di rischio dell'azienda su base 81/08.
Output: basso/medio/alto + azioni consigliate.

### Checklist Rapida
Checklist interattiva per: sicurezza, HACCP, privacy, DPI.
Output: % completamento + gap.

### Preventivo Rapido
Genera preventivo per servizi professionali.
Basato su settore, dimensione, rischi.

### Cerca Normativa
Ricerca full-text su testi normativi (D.Lgs 81/08, HACCP, GDPR).
Fonte: database interno aggiornato.

### Generatore Moduli
Genera moduli base: registro presenze formazione, verbale riunione,
scheda DPI, registro accessi.

### QR SIC-ID
Genera QR code del proprio SIC-ID.
Utile per: cantieri, presenze formazione, riconoscimento.
