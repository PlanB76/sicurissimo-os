⚙ Abilita wallet su file locale

✕

Fai questo una volta sola e il wallet funzionerà sempre su questo file.

CHROME
  1. Apri chrome://extensions
  2. Trova TokenPocket → clicca Dettagli
  3. Attiva "Consenti accesso agli URL dei file"
  4. Ricarica questa pagina (F5)
BRAVE
  1. Apri brave://extensions
  2. Trova TokenPocket → Dettagli → attiva file URL
  3. Vai su brave://settings/web3 → Estensioni
  4. Ricarica questa pagina (F5)
