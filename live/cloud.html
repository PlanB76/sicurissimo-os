Come funziona

1

Carica

Upload del documento dalla tua dashboard. DVR, attestati, manuali.

2

Archivia

Il sistema lo salva su Hostinger e, se hai Cloud IPFS, lo pinna su IPFS.

3

Certifica

Il CID del file viene registrato su BSC. Prova immutabile di esistenza.

4

Condividi

Invia il link al tuo consulente, al cliente o all ispettore. Verifica istantanea.

Cloud Base è incluso nella membership Pro (99 euro al mese) o superiore. Cloud IPFS e Cloud Aziendale sono add-on separati. Lo spazio IPFS usa Pinata come provider di pinning, i documenti restano accessibili anche se 81+ dovesse chiudere. La prova di esistenza su BSC è un hash del file registrato su blockchain, non il contenuto del file stesso.
