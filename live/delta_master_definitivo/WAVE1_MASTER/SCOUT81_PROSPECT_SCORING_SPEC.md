# SCOUT81+ PROSPECT SCORING SPEC

## SCORING MODEL

Score finale (0-100) calcolato su:

| Fattore | Peso |
|---------|------|
| Rischio attività (alto=alto score) | 25% |
| Dimensione azienda (dipendenti) | 20% |
| HACCP applicabile | 15% |
| Edilizia/cantieri | 10% |
| Ultimo contatto (più vecchio = più urgente) | 10% |
| Corsi scaduti stimati | 10% |
| Distanza dal Networker (territorio) | 5% |
| Lead storico SICURISSIMO81+ | 5% |

## FASCE SCORE

- 80-100: Prospect caldo prioritario
- 60-79: Prospect tiepido
- 40-59: Prospect freddo da lavorare
- 0-39: Prospect bassa priorità

## STATI PROSPECT

- NUOVO: mai contattato
- ASSEGNATO: assegnato a Networker
- IN_LAVORAZIONE: Networker sta lavorando
- FOLLOW_UP: da richiamare
- AUDIT_FATTO: audit completato
- PREVENTIVO: preventivo inviato
- CONVERTITO: BASIC+ o superiore attivato
- PERSO: non interessato
- DA_RIATTIVARE: inattivo da >6 mesi

## REGOLE PRIVACY

- Solo dati aziendali pubblici (Camera di Commercio, ATECO pubblica)
- No dati personali non autorizzati
- Trattamento conforme GDPR
- Provider API autorizzati con DPA firmato
- Log di ogni accesso ai dati prospect
