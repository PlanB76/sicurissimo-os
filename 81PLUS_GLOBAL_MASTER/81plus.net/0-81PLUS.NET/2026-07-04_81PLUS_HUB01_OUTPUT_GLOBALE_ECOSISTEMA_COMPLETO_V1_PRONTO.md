# PARTE 4 — IL BOT: SPECIFICA COMPLETA DI AUTOMAZIONE

@sicurissimo81_bot come **regista unico**, admin in tutte le 10 chat esistenti.

## Flusso legale di gating (identico per ogni gruppo)

1. Utente scrive al bot → bot verifica email/SIC-ID sul DB (`user81`)
2. Status confermato → link invito monouso (24h, 1 uso) al gruppo corretto
3. Status non confermato → messaggio con il percorso per sbloccare + CTA LISTINO81+
4. Welcome automatico nel gruppo: regole community + informativa privacy
5. Pass/membership scaduti → downgrade automatico con messaggio cortese, log in STAFF81+ REGIA

## Comandi utente

```
/start      collegamento SIC-ID, welcome
/pv         saldo PV+ e activity score
/rank       rank Network/Elite/VIP attuale + prossimo obiettivo
/missioni   missioni attive del giorno
/badge      badge conquistati
/status     stadio pipeline attuale + gruppi sbloccati
/aiuto      FAQ + contatto WhatsApp opt-in
```

## Regole legali cablate (ora senza gap: compensi gia vidimati)

- Filtro Semantic Guard: investimento/rendimento/ROI/APY/guadagno garantito → warn→mute→kick
- DM promozionali SOLO con consenso registrato (double opt-in GDPR)
