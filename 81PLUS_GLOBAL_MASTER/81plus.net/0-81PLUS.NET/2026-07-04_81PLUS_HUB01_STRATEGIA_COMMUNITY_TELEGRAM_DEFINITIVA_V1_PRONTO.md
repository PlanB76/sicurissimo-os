# 3. IL BOT — GATING FUNZIONALE E LEGALE AL 100%

@Sicurissimo81Bot (admin ovunque) — fonte di verita: DB unico (user81 + network81_ranks + pipeline81_stadi).

### Flusso legale di ingresso (ogni gruppo)

1. Utente clicca link → bot verifica email/SIC-ID nel DB → status reale
2. Status OK → **link invito monouso** (scade in 24h, 1 uso) → entra
3. Status non OK → messaggio con il percorso per sbloccare (CTA al LISTINO81+)
4. **Welcome legale automatico** nel gruppo: regolamento del gruppo + informativa privacy + regole community
5. Pass/membership scaduti → il bot sposta nel gruppo del livello reale con messaggio cortese (downgrade documentato nel log)

### Regole legali cablate nel bot (non negoziabili)

| Regola | Implementazione |
|--------|-----------------|
| L.173/2005 | Nessun messaggio che prometta guadagni; provvigioni SOLO su vendite reali; disclaimer automatico sotto ogni post opportunity |
| GDPR | DM solo con consenso registrato (user81.consenso_wa=1); comando /privacy con informativa; /cancellami = oblio |
| Semantic Guard | Filtro parole: investimento, rendimento, ROI, APY, staking, guadagno garantito, zero multe, rischio zero → warn → mute → kick |
| PV/PV+ | Auto-reply se qualcuno chiede "quanto si guadagna": risposta standard FAQ (compensi variabili, solo vendite reali, PV non convertibili) |
| Minori | Gruppi 18+, verifica in onboarding |
| HUMAN_APPROVAL | PUBLISH sui canali e inviti massivi = solo con approvazione Mirco (workflow GitHub manuale) |

### Gamification nel bot (collegata al DB)

- /pv /rank /missioni /badge /status — lettura live dal DB
- Rank up = annuncio automatico celebrativo nel gruppo (con scudo/pass visual del nuovo rank)
- Leaderboard settimanale per gruppo (PV+ activity, MAI euro)
- Missione del giorno pubblicata alle 08:00 in ogni gruppo status
